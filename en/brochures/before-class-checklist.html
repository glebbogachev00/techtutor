Parent Guide

Before Class Checklist

A simple setup list for parents so your child joins the trial class smoothly and confidently.

Required Steps

✓

Check your email

Confirm you received class details and the Zoom link from TechTutor.

✓

Check your messages

Confirm the Zoom link is also available in your message thread.

✓

Install Zoom

Download and install Zoom on registration day (or before class day).

✓

Test devices

Test camera, microphone, speakers, and Zoom login ahead of time.

✓

Check internet stability

Use a strong, stable connection and pause heavy downloads during class.

✓

Prepare a quiet space

Set up a calm room with minimal background noise and distractions.

✓

Keep the device charged

Plug in the laptop or ensure enough battery for the full class.

✓

Reserve one full hour

Set aside uninterrupted time for the trial session.

Helpful Extras

  • Keep a notebook and pen ready.
  • Join Zoom 5-10 minutes early.
  • Close unnecessary apps or tabs before class.
