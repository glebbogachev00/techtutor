Program explainer

What is 3D modelling?

A 3D model isn't a drawing. It's a set of points in space, joined into flat faces — and every character, prop and building you've seen in a game or a film is made this way. Drag the shape below to spin it.

Spin it, then add points

More points means a smoother surface and more work for the computer — the trade-off 3D artists make every day. Everything after this — colour, texture, lighting, animation — is layered on top of these points.

What they'll actually make

Models, built properly

Starting from cubes, spheres and cylinders in Blender, then moving to real modelling techniques — the same free tool used in studios, not a simplified toy version.

Texture, light and render

Surfaces that look like metal, wood or skin; lighting a scene so it reads; and rendering a finished image. This is where a grey shape starts looking like a photograph.

A portfolio, and some Python

Projects are portfolio-ready pieces rather than exercises, and later levels use Python to generate models — geometry described in code instead of placed by hand.

Why choose this program

Blender is the industry tool

Free, professional, and used in real studios for film, games and product design. Nothing here has to be unlearned later.

Creative and technical at once

It rewards children who like drawing as much as those who like building. The artistic side is real, but so is the spatial and mathematical thinking underneath it.

You can see the progress

3D work is visual by nature. Each week produces an image you can look at, which makes it one of the easiest programs to follow without understanding the software.

It leads somewhere

3D feeds directly into game art, animation, architecture, product design and VFX — and the Python modelling in level 3 opens the door to the programming side of it.

The tool: Blender — free and open source, and the same software used in film and game studios.
