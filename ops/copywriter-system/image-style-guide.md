# TechTutor Post Image Style Guide

## Purpose
Every organic post image should stop the scroll and feel like a moment the parent already lived. Not an ad. Not a stock illustration. A captured moment with one brand anchor.

## Core rule
One visual metaphor. One text beat. One brand accent. Nothing else.

## Format family

### Format A — Accusation Stack (best for FB/IG feed)
Three stacked chat bubbles, no phone frame. The three bubbles are the exact objections a parent has voiced or thought. The third bubble is slightly warmer/different to mark the sharpest line. Below the stack, one amber dot = the reply that changes everything.

### Format B — The Split (best for IG carousel / Reels cover)
Left/right diptych. Same person, two screens. Left = game (warm amber glow). Right = code (#193B92 glow). Center text: one line. The visual is "same focus, different object."

### Format C — The Object (best for Reddit / OG / thumbnail)
Single object on a desk or in a hand. No face. No full scene. The object is the proof: notebook with one check mark, controller dissolving into circuit lines, coffee cup next to a half-open laptop. One line of text. Sidebar-safe.

## Palette
- Background: near-black (#0a0a0c)
- Brand accent: #193B92 (TechTutor blue)
- Warm accent: amber/orange (used sparingly — only as emotional counterweight, never dominant)
- Text: white
- Font: IBM Plex Mono only

## Typography rules
- Max 2 lines per bubble / max 1 line of center text / max 1 line for Format C
- All caps only for single-word emphasis, never full sentences
- No bold, no italic, no underline in the image text
- Punctuation stays: question marks and periods. No exclamation marks.

## What is forbidden
- Faces, stock kids, laptops as hero objects, emoji, gradients beyond a single subtle glow, logos, "book now" buttons inside the image, watermarks, more than 3 text elements total.

## Image prompt template (per post)
Copy this, replace the bracketed fields:

```
Flat vector graphic, near-black background, [FORMAT DESCRIPTION].

[LAYOUT: bubbles / split / single object]

[EXACT TEXT LINES, one per line, with line breaks indicated]

[VISUAL DETAILS: glow color, outline, fill, dot, etc.]

[WARNINGS: sidebar-safe / no faces / nothing else]

Nothing-phone aesthetic. IBM Plex Mono text. High contrast.
```

## Brand consistency
- Every image should be recognizable as TechTutor at a glance: dark base, one blue accent, one amber accent, mono font, flat vector style.
- If the image could pass for a generic tech/edu post, it failed.

## Anti-patterns (hard rules)
- Do not invent details: names, quotes, settings, timings, or reactions that were not explicitly provided by the user.
- Do not reuse story beats from previous posts. Each post must open from its own confirmed moment.
- Do not reuse image formats from previous posts. Each post gets its own visual signature, even if the format family (Accusation Stack / Split / Object) stays the same.
- If the user has not confirmed a detail, ask. Do not fill the gap with "plausible marketing fiction."
- The Hung post's mother-watching beat belongs to that post only. Do not transplant it.
- The Vasco post's exact quotes and confirmed facts belong to that post only. Do not generalize them into templates.

## Sizing
- FB/IG feed: 1200 × 630px
- IG square: 1080 × 1080px
- Reddit OG / thumbnail: 1200 × 628px

All should export at 2× from the preview tool.
