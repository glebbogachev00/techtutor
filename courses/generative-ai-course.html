Lesson 2

Video & Image Creation

Video Duration: 20 minutes

Lesson Overview

Learn how to create stunning images and videos using cutting-edge AI tools like Grok, Meta AI, and Google Nano Banana. Master prompting techniques specific to different media types and discover how to bring your creative vision to life.

What You'll Learn:

  • Creating high-quality images with Grok, Meta AI, and Google tools
  • Specialized prompts for different image styles and effects
  • Video generation and animation techniques
  • How to add motion, effects, and transitions
  • Downloading and exporting media in various formats
  • Optimizing content for different platforms

AI Tools Covered:

  • Grok: Fast image and video generation with creative capabilities
  • Meta AI: Powerful models for visual content creation
  • Google Nano Banana: Efficient generation with various style options

Prompting Tips for Media:

  • Be descriptive about visual style, lighting, and composition
  • Specify animation speed, transitions, and effects for videos
  • Use reference styles and artistic movements
  • Include technical details for export quality and format

By the end of this lesson, you'll be able to create professional-quality images and videos that capture your imagination!

Lesson 3

AI-Powered Web Games

Video Duration: 22 minutes

Lesson Overview

Create interactive web games using powerful AI models like Claude, Grok, and Gemini. Learn to test different AI engines, compare their strengths, and enhance your games with advanced features to keep players engaged and challenged!

What You'll Learn:

  • Building game logic and structure with AI assistance
  • Testing and comparing Claude, Grok, and Gemini for game development
  • Implementing game mechanics (scoring, levels, difficulty)
  • Adding interactive features and special abilities
  • Increasing game difficulty and player engagement
  • Debugging and optimizing AI-generated game code

AI Models for Game Development:

  • Claude: Excellent for complex logic and detailed explanations
  • Grok: Great for creative features and rapid development
  • Gemini: Strong at code generation and optimization

Game Enhancement Strategies:

  • Progressive difficulty levels to keep players challenged
  • Power-ups, bonuses, and special mechanics
  • Leaderboards and player progression systems
  • Sound effects and visual feedback
  • Mobile responsiveness and browser compatibility

By the end of this lesson, you'll have created a fully playable web game with sophisticated AI-powered features that engage and challenge players!
