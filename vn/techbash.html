Nhiệm vụ 4 · GenAI

Yêu cầu AI trả lời bằng JSON

Mục tiêu: AI trả về mảng JSON gồm 3 khủng long với tên + fact.

Chỉ trả lời bằng MỘT mảng JSON gồm 3 khủng long. Mỗi mục có 'name' và 'fact'. Không thêm gì khác.
[
  {"name":"T-Rex","fact":"Tiny arms, huge bite."},
  {"name":"Stegosaurus","fact":"Brain the size of a walnut."},
  {"name":"Velociraptor","fact":"Had feathers, actually."}
]
✅ JSON hợp lệ · 3 mục · đủ cả hai khóa. Một prompt engineer tương lai.
