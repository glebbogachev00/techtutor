Giới thiệu chương trình

Lập trình web là gì?

Mọi trang web bạn từng dùng đều chỉ là những dòng chữ mà con bạn viết được — nội dung, kiểu dáng và chỉ dẫn để trình duyệt đọc. Hãy sửa đoạn code bên dưới, trang web sẽ đổi theo. Không có gì bí ẩn ở giữa cả.

Code thật, trang thật

Đoạn code — gõ thử vào đây

Trang web

Đó là toàn bộ công việc. Một trang web thật cũng chỉ gồm ba thứ đó — cấu trúc, kiểu dáng và hành vi — chỉ là nhiều hơn và được sắp xếp gọn gàng hơn. Không có tầng nào bị giấu khỏi con bạn cả.

Con bạn sẽ làm ra những gì

Trang web thật, không phải bài tập

Một trang cá nhân, một trang cho cửa hàng nhỏ, một dự án con tự chọn — viết trong trình soạn code thật, trên đúng loại tệp mà lập trình viên chuyên nghiệp vẫn làm việc.

Cấu trúc, kiểu dáng, hành vi

HTML quyết định trang có gì, CSS quyết định trang trông ra sao (kể cả hiển thị đúng trên điện thoại), và JavaScript quyết định trang làm được gì — menu, biểu mẫu, bộ lọc, nút bấm biết phản hồi.

Được đưa lên Internet

Dự án được đưa lên mạng qua GitHub với một đường link thật. Trang của con mở được trên điện thoại của bất kỳ ai — bạn gửi link cho ông bà và họ vào xem được ngay.

Có chế độ cốt truyện, một bảng điều khiển 2D đầy đủ và một phòng điều khiển 3D đi lại được. Viết bằng HTML, CSS và JavaScript, và đang chạy thật trên Internet.

Vì sao nên chọn chương trình này

Nền tảng nằm dưới mọi thứ khác

Ứng dụng, bảng số liệu, cửa hàng online và phần lớn công cụ AI đều chạy qua trình duyệt. HTML, CSS và JavaScript chính là thứ tạo nên chúng — đây là nền móng cho mọi thứ còn lại.

Gõ code thật ngay từ buổi đầu

Cú pháp thật, tệp thật, thông báo lỗi thật. Học cách đọc xem trình duyệt đang than phiền điều gì là một phần của việc học, không phải chướng ngại.

Thấy kết quả trong vài giây

Sửa một dòng, tải lại, thấy ngay. Vòng lặp đó đủ ngắn để giữ chân người mới — đó cũng là lý do phần lớn lập trình viên tự học đều bắt đầu từ web.

Một đường link, không phải một thư mục

Mỗi dự án kết thúc bằng một đường link chạy được. Con có thể đưa vào hồ sơ xin học, gửi dự thi, hoặc dùng làm bàn đạp cho công việc freelance đầu tiên.

Công cụ: VS Code để viết code, Chrome để kiểm tra, và GitHub để đưa lên mạng — tất cả đều miễn phí.
